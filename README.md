# 개인용 관심종목 익일 전망 및 상승 후보 스크리닝 시스템 (AlphaQuant)

한국 주식시장(코스피/코스닥)을 대상으로 한 **개인용 로컬 퀀트 트레이딩 & 익일 전망 스크리닝 시스템**입니다.  
회원가입, 결제 등 상업적 기능을 일체 배제하고, 통계적 유의성 검증(부트스트랩 95% 신뢰구간), 워크포워드 백테스트, Half-Kelly 포지션 사이징, 일일 손실 서킷브레이커, 그리고 실거래 예측 다이어리(Forward Testing Log)까지 완결된 형태로 제공합니다.

## 2. 핵심 알고리즘 및 규칙

### 2-1. Point-in-Time 기술적 스코어링 (`src/core/scoring.py`)
당일 종가 시점까지 확정된 데이터만을 사용해 0~100점 스코어 및 강세/중립/약세 라벨을 산출합니다.
- **RSI(14)**: 45~65 구간(모멘텀/눌림목 반등) 가점, 과매도(30 이하) 반등 가점
- **이동평균 정배열**: 5일선 > 20일선 > 60일선 정배열 (+25점)
- **거래량 급증비**: 당일 거래량 / 20일 평균 거래량 ($\ge 200\%$ 최대 가점)
- **볼린저 밴드(%b)**: 밴드 하단 근접 후 반등 영역($0.2 \le \%b \le 0.8$) 가점

### 2-2. 현실적 체결 모델 & 거래 비용 (`src/core/execution.py`)
- **체결 불가 필터**: 전일 상한가(+30%) 또는 익일 시가 갭상승 +15% 초과 시 매수 취소
- **거래비용**: 편도 수수료 0.015%, 매도 증권거래세 0.18%
- **차등 슬리피지**: 대형/정상 유동성 0.10%, 유동성 부족 종목 0.50%

### 2-3. 동적 익절/손절 청산 전략 (`src/backtest/exit_rules.py`)
- **목표 익절 라인**:
  - 스코어 80 이상: **+3.0%**
  - 스코어 70~79: **+2.0%**
  - 스코어 60~69: **+1.5%**
- **기본 손절 라인**: **-2.0%**
- **익일 장중 청산**: 익일 시가 진입 후 당일 장중 도달 여부에 따라 청산.
  - *보수적 백테스트 원칙*: 동일 봉에서 익절/손절 동시 도달 시 **손절 우선 처리**.

### 2-4. Half-Kelly 포지션 사이징 & 리스크 관리 (`src/core/risk_manager.py`)
- **Half-Kelly 공식**:
  $$K_{half} = 0.5 \times \left(W - \frac{1 - W}{R}\right), \quad M_{score} = \frac{\text{Score} - 50}{50}$$
  $$\text{Weight} = \min(0.20, K_{half} \times M_{score})$$
- 단일 종목 최대 투자 비중: **총 자산의 20% 이내**
- 동시 보유 종목 수 상한: **최대 5종목**
- **일일 손실 한도 서킷브레이커**: 당일 누적 실현 손실이 총 자산의 **-3%** 도달 시 당일 모든 신규 매수 강제 차단
- **연속 손절 쿨다운**: 3회 연속 손절 시 신규 매수 중단 쿨다운 발동

### 2-5. 워크포워드 검증 & 부트스트랩 95% 신뢰구간 (`src/backtest/`)
- **250거래일 In-Sample / 20거래일 Out-of-Sample 롤링 윈도우**
- **KODEX 200(069500)** 일중 수익률 1:1 매칭으로 초과수익(알파) 산출
- **1,000회 부트스트랩 리샘플링**
- **상태 배지**: 초과수익 95% CI 하한 > 0 AND 승률 95% CI 하한 > 50% 일 때 `[● 검증됨]` 점등, 미달 시 `[● 실험적]` 부여

### 2-6. 실거래 예측 다이어리 & Model Decay 감지 (`src/database/diary_manager.py`)
- 매일 15:40 관심종목 예측(스코어, 목표가)을 DB에 영구 기록
- 익일 15:40 실제 시세를 수집해 Hit/Miss 및 실현 수익률 자동 정산
- 백테스트 기대치 대비 실전 성과 저하 시 **[모델 열화 경고]** 배너 출력

## 3. 실행 방법

### 3-1. Streamlit 웹 대시보드 실행
```bash
# quant_screener 디렉터리에서 가상환경 파이썬으로 실행
& .venv\Scripts\python.exe -m streamlit run app.py
```
브라우저에서 `http://localhost:8501` 접속.

### 3-2. 단위 테스트 실행
```bash
& .venv\Scripts\python.exe -m unittest discover -s tests -v
```

### 3-3. 자동화 스케줄러 단독 실행
한국 거래일 15:40 (마감 후 정산/예측) 및 08:30 (장전 브리핑) 정기 배치:
```bash
& .venv\Scripts\python.exe -m src.automation.scheduler
```
